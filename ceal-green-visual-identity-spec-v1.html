Visual Identity Specification
Version 1.0 May 2026
Final — wordmark differentiation pending

This document is the authoritative technical reference for the CEAL Green visual identity. It defines the colour system, typography, wordmark, spacing, shape rules, and component defaults that govern all brand applications — digital, print, and internal production.

Intended for designers, developers, and agents producing CEAL Green materials. For brand purpose, personality, voice, and content strategy, refer to the CEAL Green Brand Guidelines. This specification governs visual execution; the Brand Guidelines govern brand intent.

01

1.4 — Usage Rules

  • Mangrove and Oatmeal are the dominant surface pair. In any layout, one or both must be present.
  • Aged Teak is an accent colour. It is not a background for text-heavy surfaces — contrast at body size fails WCAG AA.
  • Mid Canopy appears on dark backgrounds only (Mangrove, Near Black). Never use Mid Canopy as text on light surfaces — 1.6:1 contrast fails at all sizes.
  • Pale Sand is a warmth option for light surfaces. Use in place of Oatmeal where a warmer tone is intentional. Do not combine Pale Sand and Oatmeal as surface colours within the same layout.
  • Do not introduce colours outside this palette without explicit approval and a corresponding entry in this specification.

2.3 — Usage Rules

  • Heading hierarchy is strict: H1 → H2 → H3. Do not skip levels within a single layout.
  • Body text line-height is 1.6. Do not tighten below 1.5 for any text content above 12px.
  • Uppercase labels require letter-spacing 0.06–0.10em. Never use uppercase on body-weight text without increased tracking — it creates visual noise.
  • Aged Teak is the preferred colour for uppercase label text on light backgrounds. Its insufficient body-text contrast is acceptable at label sizes (10–12px uppercase is categorised as "large text" in WCAG at bold weight).
  • Light weight (300) is reserved for display settings and typographic contrast. Do not use 300 weight for body copy or any text below 24px.
  • Do not use Mid Canopy for any text element on Oatmeal or Pale Sand backgrounds — contrast fails at all sizes.
03

Wordmark System

The wordmark is a two-element typographic unit: CEAL (Space Grotesk 700, uppercase) and Green (Space Grotesk 500, title case). Rendered as inline-flex with a defined internal space. Colour is determined by the background it sits on — see 3.1. Typographic differentiation (tracking/weight contrast) is pending team confirmation — see 3.5.

3.4 — Avatar System

The monogram avatar is the compact representation of the wordmark — used where the full wordmark is impractical: favicons, profile images, app icons, small panel branding. The monogram replicates the weight contrast of the wordmark: "C" at 700 (CEAL weight), "G" at 500 (Green weight).

06

Application Notes

6.1 — Digital Contexts

  • Website: Oatmeal body background. Mangrove navigation. Near Black body text. Space Grotesk headings. Inter body copy. Aged Teak for CTAs and accent labels.
  • Email: White or Oatmeal background. Full wordmark in header at minimum 18px. Near Black body text. Avoid Mid Canopy as a text colour in email — rendering varies across clients.
  • Social / Profile: Circle avatar (50% radius, Mangrove background, CG monogram) for profile images. Full wordmark at 20px minimum for any branded social graphic. Oatmeal or Mangrove as primary surface.
  • Presentations: Mangrove title slides with Oatmeal and Mid Canopy hierarchy. Oatmeal content slides with Near Black body. Aged Teak for data emphasis and callouts.

6.2 — Print Contexts

  • Letterhead / Documents: Oatmeal or white background (production-dependent). Wordmark top-left, 22px minimum. Mangrove header rule.
  • Colour mode: CMYK conversions to be confirmed at print production stage. All values in this specification are screen RGB. Do not use these values unverified in print files.
  • Radius in print: Sharp corners (0px) are acceptable wherever physical production constraints make rounded corners impractical.

6.3 — Agent & Developer Use

  • All CSS custom properties are defined at :root. Use the variable names — do not hardcode hex values in component CSS.
  • Google Fonts import: family=Space+Grotesk:wght@300;400;500;700&family=Inter:wght@400;500;600
  • Wordmark structure: <div class="cg-wm"><span class="wm-c">CEAL</span><span class="wm-g">Green</span></div>. Never as a single string.
  • Wordmark colour is always set by a context class (.p-mangrove, .p-oatmeal, etc.) — never hard-coded on the .wm-c or .wm-g base selectors.
  • When building new components: follow the 8px spacing scale, use --radius: 8px as default, and apply the type hierarchy from Section 2.
